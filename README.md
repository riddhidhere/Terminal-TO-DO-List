# GKS Student Task Manager

GKS Student Task Manager is a terminal data‑management tool written in Python.

It lets you create, read, update and delete items that live in a list.

## 🚀 Key Features

* **Array Memory Allocation** – Uses Python lists as arrays to keep text data.

* **Dynamic Index Mapping** – Calculates the position of each task automatically as tasks change.

* **Memory Pop Management** – Safely removes items by using the index number keeping the rest of the list intact.

* **Type‑Safety Protections** – Contains try/except checks to stop the program from crashing when bad input is entered.

## 💻 How to Run Locally

1. Clone this repository.

2. Open a terminal inside the folder. Run:

```bash

python todo.py

```
